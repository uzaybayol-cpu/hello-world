Data Breach Runner 🔓

Warning: This is a game, not actual malware. No systems were harmed in the making of this runner.

Data Breach Runner is a lightweight, single-file HTML5 game born from a "decoy" file prank. You play as a rogue data packet attempting to infiltrate a secure system. Your goal is to bypass the red firewalls, collect data (score), and survive as long as possible.

🎮 How to Play

The game runs directly in your web browser. No installation or complex setup is required.

Controls

Input Method

Action

Keyboard

Use Left Arrow and Right Arrow keys to steer.

Mouse

Move your mouse cursor left or right to guide the packet.

Touch (Mobile)

Drag your finger left or right on the screen.

Objective

Dodge the incoming Red Firewalls.

Survive to increase your downloaded "Data" (Score).

Watch out! The system security adapts—the longer you survive, the faster the obstacles become.

🚀 Installation & Usage

Download the game.html file provided.

Double-click the file to open it in your default web browser (Chrome, Firefox, Edge, Safari, etc.).

Click (or tap) the screen to Initialize Injection (Start the game).

🛠️ Technical Details

Engine: Pure Vanilla JavaScript & HTML5 Canvas.

Audio: Real-time synthesized audio using the Web Audio API (no external sound files needed).

Responsive: Adapts to desktop and mobile screen sizes automatically.
